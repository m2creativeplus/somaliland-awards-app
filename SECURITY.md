## Reporting a Vulnerability

At M2 Creative & Consulting, security and data integrity are top priorities for institutional and consumer-facing infrastructure.

If you believe you have found a security vulnerability in this repository:

1. **Do NOT publicly disclose the issue via GitHub Issues or public discussions.**
2. Send an email with vulnerability details, proof-of-concept steps, and environment impact to:
   - **Email**: security@m2creative.site
   - **Subject**: `[SECURITY VULNERABILITY] Somaliland Digital Platform`
3. We acknowledge receipt within **48 hours** and provide a remediation plan and release timeline.
4. Once remediated, security advisories are published with appropriate attribution to the reporter.
